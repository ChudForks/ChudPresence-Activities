# ChudPresence Activities (V1)

This repository contains source for ChudPresence's official first-party Activity API V1 packages and the V1 contract.

> **V1 is not a public or community Activity development API.** This repository is published for review and transparency. V1 Activities are trusted code, not a sandbox for arbitrary third-party packages. Do not use V1 to build or publish public or community Activities.

ChudPresence continues to support its existing official V1 Activities. That compatibility does not make the V1 API an external authoring interface.

## Review the V1 source

- [Official V1 Activity packages](activities/)
- [V1 API reference](ACTIVITY_API.md)
- [V1 API contract](schemas/activity-api-v1.json)

For new public Activity development, use the programmable, sandboxed [Activity API V2](https://github.com/ChudForks/ChudPresence/blob/master/extension/ACTIVITY_API_V2.md) and the [V2 Activities repository](https://github.com/ChudForks/ChudPresence-Activities-V2).
